# EcoSort ML
EcoSort is a machine learning and neural network to detect and sort waste into compost, recycling and garbage.

# Dataset for pre-trained mode
https://www.kaggle.com/datasets/aviarvasu/dataset1?resource=download

OR Use your own dataset in this format:
//EcoSort/
//└── DS1/
//    ├── TRAIN/
//    │   ├── N/ (Trash / Garbage)
//    │   ├── O/ (Organic / Compost)
//    │   └── R/ (Recyclable)
//    └── TEST/
//        ├── N/
//        ├── O/
//        └── R/
